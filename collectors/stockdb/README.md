# Market Charts 자동 갱신

이 폴더는 로컬 stockDB의 수집 코드·설정과 GitHub 실행용 코드를 포함합니다. 원본 PC 폴더는 수정하지 않습니다.

## 운영

- **매일 08:17 한국시간**: 전일 미국 장 마감값, 상품·환율·금리·가상자산 갱신.
- **평일 17:17 한국시간**: 한국 정규장 종가와 코스피·코스닥 갱신. 휴장일에는 최근 거래일을 유지합니다.
- GitHub Actions 예약 실행은 지연될 수 있습니다. 예약 시간에 실시간 시세를 제공하는 시스템은 아닙니다.
- 수동 실행: 저장소의 **Actions → Update market dashboard → Run workflow**, `all` / `kr` / `global` 선택.
- 일봉, 주·월봉, 이동평균, 상대수익률, RS, 섹터 지수를 계산한 뒤 3개 그룹·21개 업종·모든 종목 카드 및 날짜·시계열을 검증합니다.
- 수집이 누락되거나 이력이 줄어들면 작업을 실패 처리하고 웹 파일을 커밋하지 않습니다. 기존 배포는 그대로 유지됩니다.
- FRED 국채금리 발표가 하루 늦는 경우 기존에 보관된 더 최신 값을 그대로 유지하고 로그에 남깁니다. 이 예외는 국채금리만 해당하며, 보관 값과 보조 자료가 모두 최근 7일 안에 있어야 합니다. 날짜를 앞당겨 표시하거나 과거 값으로 덮어쓰지 않습니다.
- 검증된 데이터가 바뀌면 자동 커밋하고 기존 Investment Dashboard 배포 작업을 호출합니다. 수출·공시 갱신 작업과는 독립적입니다.

## 누적 시세 보관

큰 DuckDB 파일은 Git 이력에 넣지 않습니다. `market-data-state` 사전 릴리스의 ZIP 안에 **원천 시세, 종목 마스터, 화면 그룹, 섹터 정의·매핑**만 Zstandard Parquet으로 저장합니다. 개인 계좌·보유 종목·비밀번호·API 키는 포함하지 않습니다. 공개 저장소의 릴리스 파일도 공개되며, 여기에는 원래 수집한 시장 시세와 분류만 들어갑니다.

`market-seed-v1.zip`은 최초 누적 이력을 보관합니다. 이후 `market-state-*.zip`의 최신 성공본을 복원합니다. 매번 SHA-256·행 수를 검증하며, 파생 지표 테이블은 다시 계산합니다. 새 파일의 업로드 검증이 끝난 후 자동 생성된 상태 파일은 최근 2개만 유지하고 최초 seed는 보존합니다. 잘못된 최신 파일을 조용히 과거 파일로 대체하지 않습니다.

수집·상태 저장 중 실패하면 다음 실행은 마지막 보관 상태에서 재시도합니다. 웹 커밋이 실패해도 다음 실행에서 다시 내보낼 수 있습니다. `GITHUB_TOKEN`만 사용하므로 별도 시세 API 키나 PC 상시 실행은 필요하지 않습니다. GitHub 기본 실행 알림 설정을 통해 실패를 확인할 수 있습니다.

## 범위와 한계

로컬과 같은 네이버 정규장·Yahoo Finance·설정된 FDR/FRED 대체 소스를 사용합니다. 해외 IP 접근 제한이나 공급자 장애는 실패로 표시되며, 기존 화면에 새 날짜를 임의로 붙이지 않습니다. 한국의 당일 봉은 16:30 전에 저장하지 않습니다. 미국·매크로도 뉴욕 17시 이후 확정 구간까지만 사용합니다.

**업종 매핑과 표시 종목 구성은 최초 stockDB 구성을 유지**합니다. 이 예약 작업은 가격·지표 갱신이며, 새 상장 종목 편입이나 업종 재분류를 자동으로 추정하지 않습니다. 원본 DB에서 구성을 수정한 뒤 상태를 갱신하려면 기존 seed를 덮어쓰지 말고 별도 검증된 새 상태를 올립니다.

## 개발·검증

Python 3.12에서 이 폴더를 기준으로 실행합니다.

```bash
pip install -r requirements.txt pytest
python -m pytest -q tests
python cloud_state.py pull
python cloud_update.py --region all
```

로컬 점검은 복원한 작업 DB만 변경합니다. GitHub의 상태·웹 파일을 바꾸려면 별도로 상태 업로드와 커밋이 필요합니다. `--export-only`는 수집 없이 복원한 이력으로 동일 화면을 재생성합니다. `data/`, 임시 내보내기와 DB는 Git에서 제외합니다.
