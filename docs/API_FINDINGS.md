# 관세청 4개 API 사전 조사 결과

기준일: 2026-10-01

이 문서는 공식 공공데이터포털 명세에서 확인한 내용과, 실제 인증 호출 후 추가로 확인해야 할 내용을 구분한다.

## 데이터 확보 범위와 대시보드 표시 범위

- 로컬 아카이브는 향후 분석 가능성을 위해 **모든 HS 품목을 빠짐없이 수집·보존**한다.
- 대시보드는 모든 품목을 한꺼번에 표시하지 않는다.
- 초기 관심 범위는 HS `16`~`40`, `61`~`97`이며, HS `01`~`15`와 `41`~`60`은 초기 화면에서 제외한다.
- 품목×국가 API는 국가·연도별 전체 품목 응답을 한 번에 받으므로, 제외 장을 요청 단계에서 나누면 호출 횟수가 크게 증가한다. 따라서 수집본은 전체 보존하고 표시 단계에서 필터링한다.

## 품목별 수출입실적 실제 제공 시작점

2026-10-01 실제 API 호출과 전체 백필로 확인했다.

- 1900년부터 과거 구간 표본 조회: 월 데이터 없음
- 1990~1994년 1월 조회: 데이터 없음
- `1994-01`~`1994-12` 전체 조회: 0행
- `1995-01` 단독 조회: 월 품목 데이터 7,982행과 합계 1행
- API에서 확인되는 최초 월: **1995-01**
- 로컬 저장 범위: `1995-01`~`2026-08`
- 월 범위: 380개월, 누락 0개월
- 전체 저장 행: 3,547,038행
- 고유 HS 코드 원문: 18,007개
- `1995-01` 품목 수출금액 합계는 같은 달 수출입총괄 금액과 정확히 일치

HS 코드는 대부분 10자리지만 원본 예외를 발견했다.

- 정상 10자리: 3,546,943행
- 연도별 `합계` 코드 `-`: 32행
- 품목명이 `-`인 6자리 코드: 54행
- 품목명이 `-`인 9자리 코드: 9행

비표준 행은 수집 단계에서 임의 보정하거나 삭제하지 않고 raw/Parquet에 그대로 보존한다. canonical 데이터셋을 만들 때 합계 행과 비표준 코드를 명시적으로 분리한다.

### 비표준 HS 행 조사 결과

월별 비표준 행 63개를 수출입총괄 및 같은 월의 정상 10자리 품목과 대조했다.

- 대상: 6자리 54행, 9자리 9행 (`합계` 32행은 별도)
- 발생 월: 18개월
- 비표준 행 합계: 수출 USD 242,104, 수입 USD 115,955
- 60/63행은 같은 월의 10자리 후보 또는 6자리 하위 품목을 식별할 수 있음
- 9자리 9행 중 8행은 뒤에 `0`을 붙인 10자리 코드가 같은 월에 존재
- 6자리 행 대부분은 같은 접두사의 정상 10자리 하위 품목과 함께 존재
- 이 행들은 하위 품목 합계의 중복이 아님. 2022-01을 제외한 비표준 발생 17개월에서 비표준 행까지 포함해야 품목 합계가 수출입총괄과 정확히 일치함
- 품목명은 모두 `-`이고 발생이 산발적이어서, 정상적인 HS 계층 집계행보다는 코드 변환·정정 과정에서 10자리 HSK에 배분되지 못한 잔차 또는 원천 데이터 품질 예외로 판단됨. 이는 실측에 근거한 추론이며 공식 문서에는 생성 사유가 설명돼 있지 않음

처리 원칙:

1. `date=합계` 또는 `hs_code=-`인 연도 합계 행은 월별 fact에서 제외한다. 월 데이터의 중복 집계행이다.
2. 월별 6·9자리 비표준 행은 금액·중량 집계에서 삭제하지 않는다.
3. 유효한 6자리 코드는 해당 HS6의 `residual_unallocated`로 더하되 정상 하위 10자리 실적과 구분한다.
4. 9자리 코드는 역사적 HSK master로 확인되기 전까지 자동으로 0을 붙여 덮어쓰지 않는다. 후보 코드는 별도 필드에 기록한다.
5. 매핑할 수 없는 행은 `UNMAPPED_HS` 버킷에 포함해 총액을 보존한다.
6. 총수출 KPI의 기준값은 수출입총괄 API로 두고, 품목 합계와의 차이를 `unallocated_to_hs`로 매월 공개한다.

전체 380개월 대조 결과 품목 합계와 총괄이 수출·수입 모두 정확히 일치한 달은 311개월이다. 불일치는 1996년 전월, 1997-01, 2022-01 이후 전월에 나타났다. 특히 2022년 이후 총괄이 품목 합계보다 대체로 약 0.02~0.10% 크다. 비표준 63행과는 별개의 API 집계 범위 또는 원천 품질 차이이며, 공식 설명을 확인하기 전에는 임의로 특정 HS에 배분하지 않는다.

### 생성된 HS6 데이터셋

- 범위: 1995-01~2026-08, 380개월
- 행 수: 1,824,047행
- 실제 매핑 HS6 코드: 6,863개
- `UNMAPPED_HS`: 2개 월 집계행(원본 비표준 3행)
- `UNALLOCATED_TO_HS`: 69개 월 조정행
- 원본 비표준 월별 행 63개를 금액·중량에서 보존
- 연도별 Parquet 32개 및 전체 기간 gzip CSV 1개
- 모든 월에서 HS6 수출·수입 금액 합계가 수출입총괄과 오차 0으로 일치

## 국가별 수출입실적 실제 제공 시작점

2026-10-01 실제 API 호출과 전체 백필로 확인했다.

- 1900년부터 과거 구간 표본 조회: 월 데이터 없음
- `1990-01`~`1990-12` 전체 조회: 0행
- `1991-01` 단독 조회: 국가별 데이터 184행
- API에서 확인되는 최초 월: **1991-01**
- 로컬 저장 범위: `1991-01`~`2026-08`
- 월 범위: 428개월, 누락 0개월
- 전체 저장 행: 92,594행
- 고유 국가 코드: 266개, 모두 2자리
- `(월, 국가코드)` 중복 및 국가코드 결측: 0건
- 연도별 gzip XML 36개와 Parquet 36개, 압축 손상 0건

국가 합계와 수출입총괄의 정합성에는 초기 연도 주의가 필요하다.

- 1991~1994년: 모든 월에서 국가 합계가 총괄보다 작음
- 1995년: 1개월의 수입 차이 USD 3,116
- 1996년: 5개월의 수입 차이 합계 USD 189,504
- 1997-01~2026-08: 모든 월의 수출·수입 합계가 총괄과 정확히 일치
- 차이가 가장 큰 `1991-12`를 단월로 재조회해도 연간 조회 파일과 동일했으므로 pagination 또는 연간 조회 잘림은 아님

초기 차이는 API 원천의 국가 미배분 또는 역사적 집계 범위 차이로 취급한다. raw 국가 행을 임의 수정하지 않고, 총괄과 일치해야 하는 파생 데이터에서는 `UNALLOCATED_COUNTRY` 조정행으로 별도 보존한다.

### HS 6단위 조회 동작

`hsSgn=854232`로 2025-08을 실제 조회해 확인했다.

- 품목별 및 품목×국가 API 모두 6자리 조건을 허용한다.
- 응답은 6자리 집계행 하나가 아니라 해당 접두사에 속한 10자리 하위 품목 행을 반환한다.
- 품목별 API가 반환한 7개 하위 품목의 수출금액·중량은 전체 10자리 데이터에서 `854232` 접두사를 합산한 값과 정확히 일치한다.
- 따라서 대시보드용 HS6 데이터는 추가 API 백필보다 기존 10자리 전체 데이터를 `date + hs_code[:6]`으로 집계하는 방식이 안정적이다.
- 수출단가는 하위 품목 단가의 단순평균이 아니라 `수출금액 합계 / 수출중량 합계`로 다시 계산해야 한다.

## 코드가 우선 인식하는 응답 필드

실제 XML 필드는 모두 CSV에 보존한다. 아래 필드는 발견 시 읽기 쉬운 표준 이름으로 바꾼다.

| 원본 | 표준 이름 | 의미/단위 |
|---|---|---|
| `year` | `date` | 월 (`YYYY.MM` 또는 `YYYYMM` → `YYYY-MM`) |
| `hsCd` (`hsCode`도 방어적으로 지원) | `hs_code` | HS 식별자(문자열 유지) |
| `statKor` | `product_name` | 품목명 |
| `statCd` | `country_code` | 국가 코드 |
| `statCdCntnKor1` | `country_name` | 국가명 |
| `expDlr` | `export_value_usd` | 수출 미화금액 |
| `expWgt` | `export_weight_kg` | 수출 순중량 kg |
| `impDlr` | `import_value_usd` | 수입 미화금액 |
| `impWgt` | `import_weight_kg` | 수입 순중량 kg |
| `balPayments` | `trade_balance_usd` | 무역수지 미화금액 |

## 인증키로 실제 호출한 뒤 확정할 항목

현재 실행 환경에는 인증키가 없어 아래는 아직 실응답으로 확정하지 않았다.

- 네 API 각각의 정확한 반환 컬럼 및 빈 응답의 XML 형태
- 품목명과 국가명 제공 여부 및 표기 방식
- HS 2·4·6·10자리별 반환 형태와 선행 0 보존 여부
- `totalCount`, `pageNo`, `numOfRows` 존재 여부와 실제 pagination 동작
- 요청당 최대 행 수 및 대량 응답 잘림 여부
- 빈 태그, 누락 태그, 문자열 `0`의 구분
- 품목×국가 API에서 국가 코드가 실제로 필수인지 여부
- 금액 필드가 명세 의미대로 USD 정수인지, 단위 배율이 별도로 적용되는지 여부

수집 후 `inspect` 명령의 컬럼·결측치 프로필과 raw XML을 함께 확인해 이 문서를 갱신한다.

## canonical schema 결정 유보

후보 필드(`date`, `hs_code`, `product_name`, `country_code`, `country_name`, 금액·중량·단가, `status`)는 유지하되, 네 API의 실응답 검증 전에는 하나의 canonical 테이블로 강제 병합하지 않는다. `export_unit_price`는 원본 필드가 아니라 `export_value_usd / export_weight_kg` 파생값이므로 분모 0과 중량 미제공 품목을 확인한 뒤 추가한다. 월간 확정 API의 `status`는 추후 잠정치와 결합할 때 `final`로 부여한다.
